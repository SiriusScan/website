# Installing Sirius Scan

Welcome to the Sirius Scan installation guide. Sirius is an open-source general purpose vulnerability scanner that leverages community-driven security intelligence, combining vulnerability databases, network scanning, agent-based discovery, and custom assessor analysis.

## System Requirements

Before installing Sirius Scan, ensure your system meets the following requirements:

- **Docker Engine**: Version 20.10.0 or newer
- **Docker Compose**: V2
- **Git**: Latest stable version
- **RAM**: Minimum 8GB (4GB absolute minimum)
- **Storage**: 20GB free disk space (10GB minimum)
- **Network**: Active internet connection

## System Architecture

Sirius consists of several microservices:

- **sirius-ui**: Web interface (Next.js) running on port 3000
- **sirius-api**: Backend API service on port 9001
- **sirius-engine**: Scanning engine on port 5174
- **sirius-rabbitmq**: Message broker (RabbitMQ) on ports 5672/15672
- **sirius-postgres**: Database (PostgreSQL) on port 5432
- **sirius-valkey**: Key-value store on port 6379

## Installation Steps

1. **Clone the Repository**

```bash
git clone https://github.com/SiriusScan/Sirius.git
cd Sirius
```

2. **Build and Start the Services**

```bash
# Build all services locally (recommended)
docker compose build --no-cache
docker compose up -d
```

3. **Access the Web Interface**

- Open http://localhost:3000 in your browser
- Login with default credentials:
  - Username: `admin`
  - Password: `password`

## Verifying Installation

### Service Health Checks

Check if all services are running:

```bash
docker compose ps
```

Verify UI accessibility:

```bash
curl -s -o /dev/null -w "%{http_code}" http://localhost:3000
# Should return: 200
```

View service logs:

```bash
# All services
docker compose logs

# Specific service
docker compose logs sirius-api

# Check for errors
docker compose logs | grep -i error
```

### Port Verification

Ensure these ports are available and properly mapped:

- Web UI: 3000 (HTTP), 3001 (Development)
- API: 9001
- Engine: 5174
- RabbitMQ: 5672 (AMQP), 15672 (Management)
- PostgreSQL: 5432
- Valkey: 6379

## Troubleshooting

### Critical Docker Issues

#### Issue: "pull access denied" errors

**Root Cause**: Docker trying to pull non-existent images instead of building locally.

**Solution**:

```bash
# Force local build instead of pull
docker compose build --no-cache
docker compose up -d
```

#### Issue: Container build failures

**Symptoms**: bcrypt compilation errors, dependency installation failures, Node.js build issues

**Solution**:

```bash
# Clear all Docker cache and rebuild
docker compose down
docker system prune -f
docker compose build --no-cache
docker compose up -d
```

#### Issue: Volume mount problems

**Symptoms**: Files not updating, permission errors

**Solution**:

```bash
# Check volume mounts and permissions
docker compose config
sudo chown -R $USER:$USER ./
```

### Common Issues

1. **Service Fails to Start**

   - Check service logs: `docker compose logs <service-name>`
   - Verify port availability: `netstat -tuln`
   - Ensure sufficient system resources
   - Verify Docker and Docker Compose versions

2. **Database Connection Issues**

   - Verify PostgreSQL is running: `docker compose ps sirius-postgres`
   - Check database logs: `docker compose logs sirius-postgres`
   - Ensure correct credentials in environment variables
   - Wait for database initialization (may take 30-60 seconds)

3. **Message Queue Problems**

   - Check RabbitMQ status: http://localhost:15672
   - Verify RabbitMQ logs: `docker compose logs sirius-rabbitmq`
   - Ensure RabbitMQ has sufficient memory

4. **UI Access Issues**
   - Verify sirius-ui is running: `docker compose ps sirius-ui`
   - Check UI logs: `docker compose logs sirius-ui`
   - Clear browser cache and cookies
   - Try accessing from different browser/incognito mode

### Performance Optimization

For production deployments:

- **RAM**: 8GB+ recommended for full scanning capabilities
- **Storage**: SSD storage for better database performance
- **Network**: Ensure adequate bandwidth for large scans
- **CPU**: Multi-core processor recommended for concurrent scans

### Complete Restart Procedure

If experiencing persistent issues:

```bash
# Stop all services
docker compose down

# Remove all containers and networks
docker compose down --volumes --remove-orphans

# Clean Docker system
docker system prune -f

# Rebuild from scratch
docker compose build --no-cache

# Start services
docker compose up -d

# Monitor startup
docker compose logs -f
```

```bash

git clone https://github.com/SiriusScan/Sirius.git
cd Sirius

# Start in development mode with hot reloading
docker compose -f docker-compose.yaml -f docker-compose.override.yaml up -d

# Access development tools
# UI with hot reload: http://localhost:3000
# RabbitMQ Management: http://localhost:15672
# Database: localhost:5432
```
